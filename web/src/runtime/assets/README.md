# City seal asset

`city-logo.png` is the existing City of Boulder seal extracted from a Pro map export for this private prototype. It is not AI-generated artwork. No trademark or redistribution permission is asserted by inclusion here.

Keep it in this runtime asset directory when installing the widget; PDF generation loads the built asset at `/widgets/pds-public-notice/dist/runtime/assets/city-logo.png`. If changing the widget name or hosting below a path prefix, adapt the URL in widget.tsx. Use an approved replacement when reusing this project elsewhere.
